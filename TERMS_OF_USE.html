BioLog 利用規約

文書バージョン: 2026-07-22-1 / 制定日: 2026年7月14日 / 改定日: 2026年7月22日

適用と同意

本規約は、shinosan1（以下「開発者」）が公開するオープンソースソフトウェア BioLog（以下「本ソフトウェア」）の利用条件を定めるものです。

本ソフトウェアを導入・運用する方（以下「運用者」）は、本規約およびプライバシーポリシーの内容を確認したうえで本ソフトウェアを利用してください。同意できない場合は、本ソフトウェアを利用しないでください。

本ソフトウェアについて

本ソフトウェアは、Docker 上で自己ホストして使う、家族（自分・父・母）の体温・血圧・脈拍・体重・体脂肪・食事ログ・行動ログなどを日次で記録・可視化するための個人向けツールです。データは運用者の環境内の SQLite ファイルに保存され、外部サーバーへの送信はありません。

本ソフトウェアは README 記載の通り、認証・HTTPS 前提・レート制限を実装していません。ブラウザのクロスオリジンAPI利用は許可していません。標準ComposeはUIとAPIをlocalhostだけに公開し、同一PCからの利用を前提としています。LANやインターネットから到達可能な設定への変更は想定していません。

対象と利用制限

本ソフトウェアは個人・家族規模での利用を想定しています。README「Not For」記載の通り、以下の用途は対象外です。

  • インターネットへの直接公開（認証・TLS・レート制限なしのため）
  • 同時 100 以上のユーザーでの利用（単一 Writer、SQLite ファイルのため）
  • 数百万件規模のデータ
  • リアルタイム性が必要な用途
  • 医療・介護・福祉・雇用等の業務として第三者の健康情報を管理する用途

家族データ入力時の同意

運用者が自分以外の家族（father / mother 等）の健康情報を入力する場合、運用者は記録対象となる本人から事前に同意を得てください。本人の同意なく第三者の健康情報を入力・保存しないでください。

健康・医療に関する注意

本ソフトウェアは日々の記録を補助するためのツールであり、医療行為、診断、治療、医学的助言を目的とするものではありません。表示された数値や記録内容だけで健康状態を判断しないでください。

服薬量の調整、受診の要否その他の重要または緊急の健康・医療判断を、本ソフトウェアの表示や記録だけに基づいて行わないでください。体調不良、異常値、健康上の不安がある場合は、本ソフトウェアの表示にかかわらず、医師などの専門家に相談してください。

データの保存とバックアップ

健康記録は、運用者が用意した環境の SQLite ファイルに保存されます。開発者は、保存データの永続性、バックアップ、可用性を保証しません。運用者は、README の Data Persistence に記載の手順に従い、必要に応じて自らバックアップを取得してください。

禁止事項

運用者は、本ソフトウェアの利用にあたり、次の行為を行わないでください。

  • 法令または公序良俗に反する行為
  • 他者の権利、プライバシー、名誉または利益を侵害する行為
  • 本人の同意または法令上の正当な権限なく、第三者の健康情報その他の個人情報を入力・保存する行為
  • README 記載の設計上の注意（認証なし等）を無視してインターネットへ直接公開し、第三者の安全を損なう行為
  • 不正アクセス、脆弱性の悪用、悪意あるプログラムの配布など、安全性を損なう行為
