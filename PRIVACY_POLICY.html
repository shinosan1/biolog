BioLog プライバシーポリシー

文書バージョン: 2026-07-22-1 / 最終更新日: 2026年7月22日

基本方針

BioLog は、Docker 上で自己ホストして使う個人・家族向けの健康記録ツールです。本ソフトウェア自体に、入力された健康記録を開発者（shinosan1）や第三者へ送信する機能はありません。

健康記録は、本ソフトウェアを導入・運用する方（以下「運用者」）が自ら用意した環境（Docker コンテナ内の SQLite ファイル）にのみ保存されます。開発者は、運用者が入力した健康記録を本ソフトウェアの機能を通じて受領することはありません。

本ソフトウェアには、ログイン認証、広告、アクセス解析、行動解析の機能はありません。

保存される情報と保存先

  • SQLite データベース（デフォルト ./data/biolog.db）: 体温・脈拍・血圧（収縮期／拡張期）・体重・体脂肪率・筋肉量・基礎代謝・食事ログ・行動ログ・メモなど、運用者が入力した健康記録
  • 記録は user_id（self / father / mother の3種固定）ごとに保存されます。自分以外の家族の記録を入力する場合は「家族データの取扱い」を参照してください。
  • 保存場所は、運用者が .env の BIOLOG_DATA_DIR で指定したディレクトリ、または既定の ./data です。

外部送信について

本ソフトウェアには、入力された健康記録を開発者や第三者へ自動送信する機能はありません。標準ComposeではStreamlit（8501）とFastAPI（8766）を127.0.0.1だけに公開し、StreamlitからFastAPIへはDocker内部ネットワークで接続します。LLM Local ChatからFastAPIへ連携する場合も、標準の接続先は同一PCのlocalhost:8766です。

ただし、以下は本ソフトウェアの動作とは別に発生し得ます。

  • 本ソフトウェアのソースコードは GitHub 上のパブリックリポジトリで公開されています。GitHub は、リポジトリへのアクセス時に IP アドレス等の技術情報を記録することがあります。これは GitHub 社のサービス提供に伴う処理であり、開発者が受け取るものではありません。
  • 運用者が自らの判断でクラウド VM 等インターネットに公開した場合、その通信・アクセスログは運用者が用意した環境・ネットワーク上で発生するものであり、開発者は関与・収集しません。

認証なし設計に関する重要な注意

README 記載の通り、本ソフトウェアは認証（API キー / Basic 認証 / OAuth）、HTTPS 前提、レート制限を実装していません。ブラウザのクロスオリジンAPI利用は許可していません。標準Composeはlocalhost限定ですが、バインド先をLANやインターネットから到達可能なアドレスへ変更すると、第三者が家族の健康記録へアクセスできる状態になり得ます。公開範囲とネットワークの安全管理は、運用者の責任で行ってください。

家族データの取扱い（重要）

本ソフトウェアは、運用者が自分自身だけでなく、父・母など家族の健康記録もまとめて記録・閲覧できるよう設計されています。

運用者が自分以外の家族（father / mother 等）の健康情報を入力・保存する場合、運用者は記録対象となる本人から個別に同意を得たうえで入力してください。本人の同意なく第三者の健康情報を入力・保存する行為は、その人のプライバシーを侵害するおそれがあります。

入力するデータの範囲、保存期間、閲覧できる家族の範囲については、記録対象となる本人と事前に取り決めることを推奨します。

アプリはDockerログの保存期間を設定しません。運用者はDockerのlogging driverとローテーション設定を確認してください。

データの削除

健康記録は SQLite ファイル（既定 ./data/biolog.db）に保存されています。個別の記録は各画面の編集・削除機能で削除できます。

すべてのデータを削除する場合は、docker compose down で停止した後、data ディレクトリ配下の biolog.db（-wal / -shm が残っている場合はそれらも）を削除してください。バックアップを取得していた場合、そのファイルは別途、保存先で削除する必要があります。

エクスポート（CSV）ファイルについて

本ソフトウェアには CSV エクスポート機能があります。書き出した CSV ファイルの保存場所・共有・削除は運用者が管理してください。健康情報を含む CSV ファイルを、GitHub など公開の場所へアップロードしないでください。

健康・医療に関する注意

BioLog は日々の記録を補助するためのツールです。医学的効果、治療効果、診断効果を保証または主張するものではありません。体調不良、異常値、健康上の不安がある場合は、医師などの専門家に相談してください。

問い合わせ

本ソフトウェアは OSS として無保証で提供されています。不具合報告やご質問は、GitHub リポジトリの Issues で受け付けています。

https://github.com/shinosan1/biolog/issues
